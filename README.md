# BLACK WHALE COMMAND 刷新版

Ver.1.0を直接編集せずに作成した刷新版です。フレームワークやビルド作業は必要ありません。

## ファイル

- `index.html`：画面の共通構造
- `style.css`：PC・スマホのデザイン
- `script.js`：検索、画面切り替え、カード・詳細表示
- `characters.js`：Ver.1.0から複製した既存データ
- `timelineEvents.js`：時系列イベントデータ
- `mapData.js`：船内エリア・V／VIP居住区とイベント場所IDの対応データ

## 起動方法

7ファイルを同じフォルダに置き、`index.html`をブラウザで開いてください。

画像を表示する場合は、Ver.1.0で使用していた`images`フォルダを、このフォルダ内にコピーしてください。画像がない場合は自動的にシルエットを表示します。

## 今回実装した範囲

- 勢力一覧・勢力詳細
- 人物一覧・人物詳細
- 名前検索
- 王子陣営／マフィア切り替え
- 勢力・カテゴリー絞り込み
- SAFE MODE／LATEST切り替え
- 最新モードでの死亡表示
- 監視担当の勢力詳細への表示
- PC・スマホ対応
- 相関画面（王妃→王子→陣営、監視元→監視先、王子→マフィア）
- 時系列画面（航海日／話数、人物・勢力・事件種別フィルター）
- 航海図画面（V／VIP居住区、全体マップ、主要イベント時系列の連動表示）
- 居住区の部屋番号、各層の常設エリア、船全体・船外・複数地点イベントの表示
- 画面高が低いPCでも操作できるスクロール対応・コンパクト表示
- 勢力詳細から人物詳細を開いた場合の遷移元復元
- 王子陣営詳細の王妃・守護霊獣画像、守護霊獣説明、念能力説明

## データについて

`characters.js`の内容は変更していません。既存データで`groupType`が未設定の人物は、表示時だけ「王子陣営」として扱います。
